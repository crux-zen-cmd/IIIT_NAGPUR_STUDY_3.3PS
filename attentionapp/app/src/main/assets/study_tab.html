1. The Optimal Substructure Principle

A problem exhibits optimal substructure if an optimal solution to the problem contains within it optimal solutions to subproblems.

// Fibonacci with Tabulation (Bottom-Up) function fib(n) { let dp = [0, 1]; for (let i = 2; i <= n; i++) { dp[i] = dp[i - 1] + dp[i - 2]; } return dp[n]; }
